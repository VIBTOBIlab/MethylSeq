All the parameters of the pipeline, generated from the parameter schema (`nextflow_schema.json`) used to validate them when the pipeline starts. See the [usage](/MethylSeq/usage/) page for how the parameters work together, e.g. the [library types](/MethylSeq/usage/#library-types), the [removal of optical duplicates](/MethylSeq/usage/#removal-of-optical-duplicates) or the [CpG-level sequencing saturation](/MethylSeq/usage/#cpg-level-sequencing-saturation).

The parameters can be given on the command line (e.g. `--rrbs`) or in a parameters file (`-params-file params.yaml`). Parameters hidden in the help message (`--help`) are not listed.
