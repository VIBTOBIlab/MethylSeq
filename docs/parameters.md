# Parameters

All the parameters of the pipeline, generated from the parameter schema (`nextflow_schema.json`) used to validate them when the pipeline starts. See the [usage](usage.md) page for how the parameters work together, e.g. the [library types](usage.md#library-types) and the [modules added to nf-core/methylseq](usage.md#modules-added-to-nf-coremethylseq).

The parameters can be given on the command line (e.g. `--rrbs`) or in a parameters file (`-params-file params.yaml`). Parameters hidden in the help message (`--help`) are not listed.
